## [1.0.0] - 2026-07-28

### Added

- Public MIT-licensed product packaging.
- Bilingual Vietnamese and English documentation.
- VitePress documentation website with local search.
- Memory-only workspace as the default.
- Explicit Memory snapshot export/import safety contract.
- Windows clean-machine migration and release checks.

### Changed

- Unified the plugin runtime as the product source of truth.
- Replaced the PDF dependency that required AGPL or a commercial license.
- Standardized public package metadata under John-IDK.
