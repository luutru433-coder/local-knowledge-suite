# Support

Community support is provided only through
[GitHub Issues](https://github.com/luutru433-coder/local-knowledge-suite/issues).

Before opening an issue:

1. update to the latest tagged release;
2. ask Codex: `Use $manage-local-knowledge to run project doctor for the
   current project and summarize only redacted diagnostics`;
3. read the troubleshooting guide; and
4. search existing issues.

For direct PowerShell diagnostics, first resolve the installed `$PluginRoot`
with the verified snippet in the
[quick installation guide](https://luutru433-coder.github.io/local-knowledge-suite/en/guide/getting-started).

Include the plugin version, Windows version, installation mode, command or MCP
tool used, expected result, actual result, and a redacted error message.

Never post passwords, tokens, private source excerpts, Memory snapshots,
company names, local usernames, or full machine paths. Replace them with safe
fictional values.

There is no private support email, paid support, or SLA in v1. Report security
problems through the private process in [SECURITY.md](SECURITY.md).
