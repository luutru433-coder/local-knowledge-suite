## A small example

Three applications for one fictional company have separate technical decisions
but reuse the same cited warranty policy:

```text
Store project   ─┐
Support project ─┼─> shared cited Company Knowledge
Internal tool   ─┘

Each project ─────> its own private Memory
```

Use Memory-only when this project does not need company evidence:

```text
Use $manage-local-knowledge to initialize this project as memory-only.
```

V1 does not rebind an initialized project. If the project needs company
evidence, register the company first and choose `combined` during initial
bootstrap instead of hand-editing the manifest.
