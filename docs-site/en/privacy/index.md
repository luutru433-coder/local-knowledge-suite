# Privacy policy

Local Knowledge Suite is local-first and includes no telemetry or analytics.
Data leaves the machine only when a user explicitly configures a Git remote,
public website crawl, export, or sharing. Model inference is restricted to a
local loopback LM Studio endpoint.

Read the
[full privacy policy](https://github.com/luutru433-coder/local-knowledge-suite/blob/main/PRIVACY.md)
and the [privacy and security guide](/en/reference/privacy-security).
