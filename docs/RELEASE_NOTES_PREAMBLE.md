This release contains the complete, buildable source product. Its assets
include the full-source ZIP, `SHA256SUMS`, a CycloneDX SBOM, normalized Python
and Node license inventories, and exact third-party notices.

Verify downloaded assets against `SHA256SUMS` obtained from this same trusted
GitHub Release channel before use.

Annotated-tag/main-head binding and SHA-256 checks provide provenance and integrity only against the trusted GitHub Release channel. They are not a cryptographic signature or an independent attestation.

Install the marketplace and plugin at the exact immutable tag for this release.
Review `CHANGELOG.md`, the installation guide, and the migration guide before
upgrading an existing project.
