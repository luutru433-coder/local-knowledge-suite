# Northstar Bicycle Labs — fictional example

Northstar Bicycle Labs is invented for Local Knowledge Suite documentation.
It is not a real company and contains no real customer, employee, product, or
policy data.

## Try the example

1. Create a new company repository named `Northstar Bicycle Labs`.
2. Copy files from `sources/` into the repository's ignored
   `.local-sources/` directory.
3. Register each file with `company source-add`.
4. Queue and run ingestion.
5. Review generated claims and their exact excerpts in the portal.
6. Attach a separate test project using profile `combined`.
7. Try prompts from `prompts.vi.md` or `prompts.en.md`.

Do not turn the `sources/` directory itself into canonical `knowledge/`.
Canonical knowledge must be generated and reviewed through the normal evidence
pipeline.
